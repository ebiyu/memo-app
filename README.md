# memo

書式なしプレーンテキスト専用の付箋メモ。中身はただのテキストファイルなので、Claude Code など外部のツールから読み書きできる。

> 以前は memo サーバー (FastAPI + SQLite + MCP) と同期していた。その最後の版はタグ `server-sync` に残してある (`git checkout server-sync`)。

```
src/memo/
  core/      slug 検証・3-way merge (git 互換コンフリクトマーカー)
  desktop/   wxPython 付箋 UI + ローカル保存
tests/
```

## セットアップ

```bash
uv sync
```

## 起動

タスクトレイに常駐する。設定と既定のメモは `%APPDATA%\memo` に置く:

```bash
uv run memo-desktop
```

別のデータフォルダで起動する:

```bash
uv run memo-desktop --data-dir ./tmp/client-b
```

### 保存先

| メモの作り方 | 保存先 |
|---|---|
| 新規メモ (slug を入力) | `%APPDATA%\memo\notes\<slug>.txt` |
| ファイルを開く | 開いたファイルそのもの |

- 一度開いたファイルは覚えておき、「メモを開く」の一覧に出る。開いたまま終了すれば、次回の起動時にも開く。
- 開いたファイルの「削除」は「一覧から外す」になる。ファイル自体は消さない。
- 開けるのは UTF-8 のテキストだけ (BOM の有無は問わない)。書き戻すときは、読み込んだときの BOM と改行コード (CRLF / LF) を保つ。

### 操作

| 操作 | 方法 |
|---|---|
| 新規メモ | トレイアイコンをダブルクリック / メニュー「新規メモ…」/ 付箋で `Ctrl+N` |
| ファイルを開く | トレイメニュー「ファイルを開く…」/ 付箋で `Ctrl+O` |
| メモを開く・閉じる | トレイメニュー「メモ」 |
| 付箋を前面に出す (どこからでも) | `Ctrl+Alt+M` |
| 行を上下に移動 | `Alt+↑` / `Alt+↓` |
| 現在行の下に新しい行を挿入 | `Ctrl+Enter` |
| 選択なしで行ごとコピー・カット | `Ctrl+C` / `Ctrl+X` |
| 最前面の切替 | `Ctrl+T` |
| 背景の半透明切替 (文字は不透明のまま) | `Ctrl+Shift+T` |
| 今すぐ保存 | `Ctrl+S` |
| 閉じる (メモは残る) | `Ctrl+W` / × |
| 削除 (開いたファイルは一覧から外す) | `Ctrl+Shift+Delete` |

入力は 0.7 秒でファイルに自動保存される。付箋が非アクティブになったときと閉じたときにも保存する。

タイトルの `●` は未保存の入力あり、`⚠` はコンフリクトマーカーありを示す。

## 外部のツールによる変更の取り込み

- 開いているファイルを 0.5 秒ごとに確認する。変化に気づいたら、次の確認でも同じ状態であることを待ってから読み込む (書きかけを読まないため)。
- 付箋の側は「最後にディスクと一致した内容」を覚えておき、3-way merge の共通祖先にする。
  - 付箋が未編集なら、ディスクの内容に置き換える。
  - 未保存の入力があれば `merge3way(base, 付箋, ディスク)` する。重ならない変更は自動マージして保存する。
  - 重なる変更は `<<<<<<< local` / `=======` / `>>>>>>> remote` を本文に書き出し、付箋のタイトルに ⚠ と赤背景で表示する。マーカーはファイルにも書き出すので、Claude Code に解消を頼むこともできる。
- 付箋の内容が変わっていなければファイルに書き込まない (外部ツールの「読んだ後に変更された」検知を無駄に起こさないため)。
- 外部で削除されたとき、付箋が未編集なら閉じて一覧からも外す。未保存の入力があればファイルを作り直す。
